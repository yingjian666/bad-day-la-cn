# v1.1

## 下载

| 文件 | 大小 | 说明 |
|---|---|---|
| `BadDayLA_CN_v1.1.zip` | 4.13 MB | 含 3 套实际使用的字库 |

解压后约 30.4 MB，覆盖到游戏根目录即可。

## 安装

1. 备份游戏目录（至少 `BadDayLA.exe`、`Resource\`、`script\`）
2. 把压缩包内所有文件夹解压覆盖到游戏根目录
3. 运行 `BadDayLA.exe`

补丁不含 `CONFIG.DAT` 与 `SAVE\`，不会覆盖画面设置与存档。

**字库只在游戏启动时加载一次**：游戏运行中覆盖不会生效，必须先完全退出进程。
