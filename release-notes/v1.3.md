# v1.3

本版是 v1.2 之后的一轮细节修正，集中在三处「看得见但不显眼」的问题上。

---

## 一、HUD 状态标签一直是德文

`int8x6\maingame.dds` 是左上角头像区那张 HUD 贴图。中文版这张图误用了**德语版**作为底图，导致三个状态标签一直是德文：

| 英文原版 | 修正前 | 现在 |
|---|---|---|
| `STINKY!` | `Stinkend` | 发臭 |
| `DRUNK` | `BETRUNKEN` | 醉酒 |
| `ZOMBIFIED!` | `VERSEUCHT!` | 已感染 |

德语版和英文版字形接近，这个错误一直没被发现。中文版这张图是 2025-10-29 改的，英文原版则是 2006-02-13 的原始文件。

### 怎么修的

原图是 1024×1024 的 **DXT3** 压缩贴图（1048704 字节，透明背景）。手头没有 DXT3 编码器，所以：

1. 用 Pillow 解码成 RGBA；
2. 只擦除文字像素（按低饱和度筛选），头像、图标、荧光底全部保留；
3. 用黑体重绘中文，黑字白边，字号按原文实测（`Stinkend` 高 12px、`BETRUNKEN` 高 17px、`VERSEUCHT!` 高 9px）；
4. 对比修改前后的图，**只重编码有变化的 574 个 4×4 块**，其余块从原文件原样复制；
5. 手写 DXT3 块编码器写回：8 字节 alpha（16×4bit）+ 2 字节 c0(565) + 2 字节 c1(565) + 4 字节索引。

只重编码变化块，是为了把压缩损失限制在文字区域，头像和图标保持原始数据。

`VERSEUCHT!` 底下那层黄绿荧光条（`RGB(198,223,66)`）不是文字，是原图的底色，已原样保留。

## 二、招募提示的对象错了

```
EN  : 109|RECRUIT|1|Press E BUTTON to give BANDAGES to others.
v1.2: 109|RECRUIT|1|按 E 键把绷带交给同伴。
v1.3: 109|RECRUIT|1|按 E 键把绷带交给路人。
```

`others` 被译成「同伴」，玩家会去找队友，但游戏里**没有**「把物品交给同伴」这个机制——按 E 或 F 对队友完全没反应。

判断依据：

- 英文用 `others`，不是 `companion` / `teammate`；
- 键名组是 `RECRUIT`（招募）；
- 关卡脚本 `map\*.spx` 里 `UNIT` 全是平民模型（`WOMAN04` / `FATMAN01` / `OLDWOMAN01`），与 `RECRUIT_ITEM`（招募礼物，如大汉堡）按坐标混排；
- 同一份表的 `115|HINT|21|Ask others for DIRECTIONS!` 译作「向别人问路」，`others` 在这里没有译偏。

## 三、增益说明因全角字符整条不显示

`POWERUP` 组的三条说明里混入了全角空格、全角加号、全角数字：

```
原：生命上限　＋１！     → 左下角一片空白
现：生命上限加一！       → 正常显示
```

注意这不是缺字——离线渲染器能把这三个字正常画出来。更可能与全角空格有关：字库的 `first` 边界正是 `0xA1A1`，而全角空格的编码就是 `A1A1`。

`POWERUP|3` 同样处理，`一口闷！Ｊｕｌｋｙ　伤害翻四倍！` 改为 `一口闷！朱奇果汁伤害翻四倍！`。

## 四、术语统一：撬胎棍 → 撬胎棒

`item\item.res` 里这个物品的名字一直是「撬胎棒」，但对话与提示写的是「撬胎棍」，同一件武器两个名字。本版统一为「撬胎棒」，共 18 处：

- `Resource\t_interf.txr`、`t_interfX.txr` 各 1 处（招募提示）；
- `script\scenario\level1.dlg` / `.dlx` / `level1_de.dlg` / `.dlx` 各 3 处；
- `script\scenario\earthquake.dlg` / `.dlx` / `earthquake_de.dlg` / `.dlx` 各 1 处。

`TIRE IRON` 的通行译法是「撬胎棒」或「轮胎撬棍」，原译「撬胎棍」是自造词。
