## 安装

1. 备份游戏目录（至少 `BadDayLA.exe`、`Resource\`、`script\`）
2. 把压缩包内所有文件夹解压覆盖到游戏根目录
3. 运行 `BadDayLA.exe`

补丁不含 `CONFIG.DAT` 与 `SAVE\`，不会覆盖画面设置与存档。

**字库只在游戏启动时加载一次**：游戏运行中覆盖不会生效，必须先完全退出进程。

## 变更

### 修复

- **过场动画播放崩溃**：L3 等影片播放到数秒后弹出 `xvidcore.dll` 错误窗口
  （Exception Code C0000005，固定偏移 `0x47F0D`，Read Address 落在页边界）。

  根因是 AVI 容器内存在 **0 字节的空帧**。原片里有大量 7 字节的跳过帧（画面不变），
  ffmpeg 读取时把它们判为无效直接丢弃（12 秒只解出 351 帧而非 360），
  编码器随后用 0 字节 packet 占位。系统 `xvidcore.dll`（2004-12-20 版）
  拿到空数据仍去解析帧头，越界读导致崩溃。

  修复方式：编码时在**输出侧**加 `-r 30`，按恒定帧率重采样并用前一帧补齐被丢弃的位置；
  再用 `-frames:v` 以原片帧数为上限，防止重采样多补帧。
  8 部影片的帧数、时长、分辨率现与原片逐项一致，0 字节帧为 0。

### 新增

- **顶部术语注释**：字幕支持 `@TOP@` 行首标记，可把术语解释放到画面上方（Alignment 8），
  字号 26，不遮挡底部对话字幕。已用于 L5 的 FUBAR 注释（00:01:06 - 00:01:08）。

### 变更

- L5、L8 字幕重新校对。
- `subtitle/` 目录同步为最新校对版。

### 未变

- 纯文本包内的文本、字库、主程序与 v1.1 完全相同（SHA256 一致：
  `2fca80cbe66ce97299b3cae0b53a49061c26cce015a2ea87f50015f670fa1158`）。
